# Ledgerly

Ledgerly is a modern personal finance and wealth management platform designed for privacy, clarity, and control over your financial life.

## Overview

Ledgerly provides an all-in-one workspace to track personal cash flow, investments, and receivables with private, isolated user workspaces.

## Key Features

- **Consolidated Net Worth Tracking**: Monitor total wealth across bank accounts, cash reserves, equity holdings, and fixed deposits.
- **Transactions & Ledger**: Categorize income and expenses with real-time balance calculations, transfer tracking, and duplicate prevention.
- **Investment Management**: Track stocks with weighted aggregate returns and fixed deposits with automated accrual calculations.
- **Split & Shared Expenses**: Manage shared expenses and receivables with friends, track partial repayments, and resolve balances.
- **Monthly Analytics & Recaps**: Interactive charts and budget metrics for consumption patterns and savings rates.
- **Data Privacy & Security**: Isolated user accounts, secure authentication, session management, and owner-scoped data access.
- **Data Portability**: Export your transaction ledgers to CSV at any time.

## Tech Stack

- **Framework**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS
- **Database & ORM**: PostgreSQL, Prisma
- **Authentication**: Better Auth
- **Visualizations & Math**: Recharts, Decimal.js
